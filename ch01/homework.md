a) 
 
Advantage - Cheap because all devices are connected to network via a single cable
Disadvantage - Break in this cable affects all devices connected to that network

b)
  
Advantage - Each device is connected to network via its own cable to the central switch so a fault in one cable affects only that device and not all devices on the network
Disadvantage - The central device (switch or hub) is a single point of failure. If it fails, the whole network goes down

c)
  
Advantage - All devices are linked to each other via cables so very fault tolerant meaning, there are several routes between any two devices. If one cable fails, data takes another path
Disadvantage - Very expensive because a new device needs cables to connect to all existing devices so links grow very fast and quickly become unmanageable. 
e.g. The formula for number of links/cables needed is n ( n - 1 ) / 2, so 5 devices need 10 cables but 10 devices would need 45.
